# Contributing

Thanks for helping improve BookGloss. Keep changes focused on its single purpose: collecting unfamiliar words while reading.

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make the change and add or update tests where useful.
4. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
5. Open a pull request explaining the user-facing effect.

Please avoid adding accounts, gamification, analytics, or infrastructure that makes the self-hosted app harder to understand.
